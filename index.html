APCD

Auto-Project-Context-Doc

Concise project docs and a Progress list, so any new AI coding session picks up where you left off.

1

Install

claude plugin marketplace add Karthikeshwar1/APCD
claude plugin install apcd@apcd
2

Run it in any project

/apcd:run

It reads your repo, shows a short plan, and applies on “yes”. Safe to re-run. Keep the apcd: prefix, since /run is built in.

3

Pick up later

In any session or tool, say pick up where we left off.

What you get

CLAUDE.md (or AGENTS.md if you use other tools), and docs/<topic>.md for long topics.

The entry file stays under about 150 lines, with these sections: Decisions, Rules, Docs, Progress (Next, Done last 3, Notes). Empty sections are omitted.

Safe by design

  • Edits docs only, never your code, never git commit.
  • Existing docs are copied verbatim to docs/ before any shortening.
  • Existing progress trackers are linked, not duplicated.
  • No secrets, emails or personal paths are written.
  • Re-running with nothing changed is a no-op.

Works with

  • Claude Code (reads CLAUDE.md).
  • Codex, Cursor, Copilot (read AGENTS.md).
  • Gemini CLI (GEMINI.md gets @AGENTS.md added at the top).
  • Aider (add read: AGENTS.md to .aider.conf.yml yourself).

Limits

  • Commit your docs before running it, then review the diff.
  • Rules are advisory text, so small models skip them more often. On a very large hand-written entry file, haiku once in three runs rewrote it without keeping the copy (sonnet kept all facts).
  • It may add a filler Next item on repos with no TODOs.
  • Tested with headless Claude runs on fixtures.
