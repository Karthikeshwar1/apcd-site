What APCD is

APCD is a plugin for Claude Code. It has no server, no account, no analytics and no telemetry. It makes no network requests and uses no connectors, MCP servers or hooks.

What it does when you run it

It reads project files (README, docs, code) in your own folder. It writes only markdown files (CLAUDE.md, AGENTS.md, docs/) into that same folder, on your own device.

The plugin itself collects, stores and transmits nothing. APCD retains no data.

Your Claude session

File contents the model reads pass through your normal Claude session. That session is governed by your own Claude and Anthropic settings and policies, not by APCD.

Secrets

The skill instructs the model never to write secrets, keys, emails or personal paths into the docs. This is an instruction, not a guarantee, so review the diff before committing.
